# Синий дом / Blue Home 1.2.0

[Скачать APK](https://github.com/nachezy/blue-home/releases/download/v1.2.0/blue-home.apk)

Простой домашний экран Android TV с часами, датой и иллюстрированным фоном с котами.

- Добавление установленных приложений на главный экран и их настоящие иконки.
- Удержание OK или Menu: перемещение, переименование, замена приложения, удаление плитки с главного экрана.
- Дополнительные ряды прокручиваются пультом.
- AdGuard VPN и RuStore вынесены в отдельную нижнюю панель.
- Порядок и названия сохраняются. Назначения из версий 1.0/1.1 переносятся при первом запуске.
- Ссылки для установки доступны в настройках.

Передайте APK через FilePulse и установите поверх предыдущей версии без удаления. VPN и магазин устанавливаются отдельно; кнопка VPN открывает приложение и не отражает состояние подключения.

Редактор оформления, импорт/экспорт и удалённые настройки пока остаются в бэклоге.

Подпись, целостность APK, повышение версии и совместимость сертификата проверены. Автоматические проверки охватывают перенос назначений и операции с порядком плиток. Эта версия пока не проверена на реальном телевизоре или эмуляторе.
