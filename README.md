# Синий дом / Blue Home

Лёгкий домашний экран для Android TV: часы, дата и ярлыки Кинопоиска, VK Видео, YouTube и Twitch. Есть список приложений, настройки и кнопка запуска отдельно установленного AdGuard VPN.

## Скачать

[Скачать blue-home.apk](https://github.com/nachezy/blue-home/releases/download/v1.0.0/blue-home.apk)

Откройте ссылку в браузере телевизора, скачайте APK и запустите установку. Если Android запросит разрешение на установку из браузера, разрешите его для этой установки.

Приложение не содержит сами видеосервисы или VPN: их нужно установить отдельно. Замена домашнего экрана зависит от возможностей прошивки телевизора.
